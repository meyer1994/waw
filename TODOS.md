# Full Endpoints Implementation Status

## Pagination Findings
Pagination was dropped: list endpoints request the upstream max of `itens=100` (upstream max per request). The upstream supports `pagina`&`itens` (verified, undocumented in the OpenAPI spec) for /proposicoes, /votacoes, /eventos, /orgaos, /deputados/{id}/despesas — but there is no total/page-count field in the response, only `links` (self/first/next/last).
